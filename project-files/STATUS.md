## 🚀 How to Get Started

1. **Run backend**: `cd backend && python manage.py runserver`
2. **Run frontend**: `cd frontend && npm start`
3. **Set up APIs**: Add BRIGHT_DATA_API_KEY and OPENAI_API_KEY to .env
4. **Create sample data**: Use Django admin
5. **Test endpoints**: Use Postman or curl
